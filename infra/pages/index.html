Seattle Crime Forecast — live data

This address hosts the data behind the Seattle Crime Forecast dashboard: area-level (500 m) forecasts of crimes reported to the Seattle Police Department, refreshed every hour by a scheduled GitHub Actions job. It is a research and public-understanding project, not a tool for policing or for judging individuals.

  • data/meta.json — models, categories and grid
  • data/forecasts/index.json — frozen forecasts
  • data/health.json — data freshness and job status

The document formats are described in docs/API_CONTRACT.md in the source repository.
